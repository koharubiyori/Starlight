## Startlight

Startlight is an Android client for [Sunshine](https://github.com/SunshineStream/Sunshine), similar to [Moonlight for Android](https://github.com/moonlight-stream/moonlight-android).

This project may no longer receive updates because I found [this project](https://github.com/AlkaidLab/foundation-sunshine), which already includes everything I had planned to develop for Sunshine and Moonlight.

You can use Startlight as a Sunshine client, but I haven't tested input from physical devices.

This project is built using Jetpack Compose and a single-activity architecture. If you're planning to develop a new Android client for Sunshine, you may find this project useful.
